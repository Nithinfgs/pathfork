# Code of conduct

Be respectful. Assume good faith, keep discussion about the code and the problem, and give feedback you would want to receive. Harassment, personal attacks and discrimination are not welcome here.

Maintainers may edit or remove comments, commits and issues that break these rules, and may block repeat offenders. To report a problem, contact the maintainer through the email on their GitHub profile.

This is a short adaptation of the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which applies where this document is silent.
